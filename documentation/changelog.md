# Changelog

All notable changes to the BakeStudio project are documented in this file.

## [2.0.0] - 2026-10-06
### Added
- Complete single page architecture with 12 sections.
- Interactive Cake Customizer with live shape, size, color swatch, and toppings preview.
- Instant Pricing Calculator with odometer countup and bulk discount tier engine.
- Interactive Delivery Slot Calendar and hourly slot selection grid.
- 5-step booking wizard with client-side form validation and order receipt generator.
- Single-page overlay Baker / Admin and Customer Dashboards.
- Interactive Kanban Baking Queue and inventory level tracker with low-stock warnings.
- 3D Tilt Card engine on all cards with center-aligned text/icons and bakery-themed hover animations.
- 39 unique, locally stored, high-resolution WebP images.
- WCAG 2.1 AA accessible accordion, skip link, and keyboard navigation.
- Dedicated supporting pages: `pages/404.html` and `pages/coming-soon.html`.
- Production XML Sitemap, robots.txt, and comprehensive documentation suite.
