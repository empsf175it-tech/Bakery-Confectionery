# Installation & Setup Guide

## BakeStudio

This project is built using modern vanilla HTML5, CSS3, and ES6+ JavaScript. It requires **zero compilation steps**, **no heavy frameworks**, and **no bundlers** to run.

---

### 1. Quick Start (Instant Run)

1. **Direct File Open:**
   Simply double-click [`index.html`](file:///c:/Users/prasa/OneDrive/Desktop/SF/own%20project/Oct/Bakery%20&%20Confectionery/index.html) in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

2. **Using VS Code Live Server:**
   - Open this workspace in Visual Studio Code.
   - Install the **Live Server** extension.
   - Right-click `index.html` and select **"Open with Live Server"**.
   - Your site will launch at `http://127.0.0.1:5500/`.

3. **Using Python Local Web Server:**
   Open PowerShell or Terminal in the root folder and run:
   ```bash
   python -m http.server 8000
   ```
   Navigate to `http://localhost:8000` in your browser.

4. **Using Node HTTP Server (Optional):**
   ```bash
   npx serve .
   ```
